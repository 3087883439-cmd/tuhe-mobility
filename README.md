# 途合 Tuhe Mobility

面向个性化出行的 WebGIS 研究原型：比较步行/骑行接驳公共交通，并在可调方向兴趣区中查找顺路商户。

当前版本：**v0.6.0**。程序在本机运行，尚未部署公众在线服务，也未完成 ChatGPT MCP 插件接入。

## 已实现

- 步行与骑行共享地铁站候选，按实际到站时刻查询后续公共交通，指定站名对两种接驳均生效。
- 按有车偏好展示方案，同时标明有限候选中全程最快的路线。
- 完整行程按步行、骑行、公交和地铁分色高亮，显示换乘与上下车点；缺失线路可单独补查。
- 可调100—5000米的方向兴趣区及距离变化张角，地图高亮并自动缩放至区域。
- 区内商户点可视化、评分与直线距离权重排序、时间条件通过候选中的推荐星标。
- 商户加入活动后重算行程；停车、营业、供应和具体餐品价格未知时保留待核实。

## 运行

需要 Node.js 22 或更新版本，无第三方运行依赖。

Windows：下载并完整解压源码，双击 `start.cmd`。

其他系统或终端：在项目根目录运行：

```sh
npm start
```

打开 http://127.0.0.1:8787 。在网页“连接设置”输入自己的高德 Web服务 Key；显示真实底图另需 Web端 JS API Key 及对应安全密钥。不要把凭证写入源码或提交到仓库。

详细说明见 [先看这里](先看这里.md)。更新时先关闭旧程序终端，确认网页版本为v0.6.0。

## 检查

44项模拟检查通过，覆盖接驳、时间、候选遗漏回归、地图覆盖物、兴趣区边界、缺评分回退及本机HTTP流程。模拟检查不是实际南京路线验证，也不是论文方法效果。现有交付环境未配置真实账户，尚未完成真实高德底图联调。

## 数据来源与边界

高德POI明确标为高德数据。美团目前仅支持用户有权使用的商户坐标文件导入，模板在 `examples/`，没有连接美团实时API。

地图、商户和时刻估计来自用户配置的第三方服务。兴趣区是方向几何粗筛，不是道路等时圈；有限半径、分页、预算和接口候选仍可能遗漏更优方案。星标只比较本次已通过时间精算的候选，不保证营业、价格、停车或现实准时。

本项目只含程序、说明和合成测试，不包含个人轨迹、研究原始接口快照、真实账号Key或真实授权商户清单。代码公开使用许可由项目作者另行确定，当前不附第三方数据开放许可。

## ChatGPT接入路线

下一阶段将核心能力包装为MCP工具：地点检索、出行候选比较、兴趣区商户推荐、加入活动后重算。当前本机HTTP接口不是MCP接口。

公众部署需新增独立用户会话、认证、限额、服务端凭证管理及生产HTTPS端点。现有服务只接受本机主机名，不能仅改监听地址就当成公众服务。
