# 美团授权商户导入

这里只是结构模板，没有附带真实商户数据。导入只说明用户已声明授权，不表示程序或美团核验了授权。

取得有权使用的商户数据后，在模板中填写真实授权依据，并将 authorization_confirmed 改为 true。merchants 中每个对象需要：

| 字段 | 含义 |
|---|---|
| id | 原始商户ID，不能重复 |
| name | 真实门店名称 |
| location | GCJ-02经度,纬度，必须对应这家分店 |
| address | 可选，门店实际地址 |
| category | 可选，类别，如早餐、咖啡 |
| keywords | 可选，供本地筛选使用的真实商户关键词 |
| average_price | 可选，人均消费参考，缺失用null |
| rating | 可选，数据来源提供的评分，缺失为null，不用人均价格代替 |
| rating_max | 可选，评分量表满分；可在整个文件或每条商户上声明，默认5；例如10分制应显式填写10 |
| hours | 可选，原始营业描述 |
| url | 可选，美团或大众点评的HTTPS门店地址 |

禁止把高德商户换一个来源标签就当成美团数据。坐标若来自其他坐标系，应先通过授权允许的坐标转换渠道处理，不能只把crs字段改为GCJ-02。

导入数据按名称、地址、类别和关键词作文字匹配。检索“早餐”没有结果时，可查询具体店名，不能把没有该关键词理解为店铺不存在。

官方商企通到餐列表的公开文档没有承诺返回可直接导航的门店坐标。没有坐标的条目不能直接加入本工具，需补足经许可取得且人工核对分店的坐标，不按相同名称自动合并。人均价也不能当成某份早餐的价格。

本工具目前没有实时调用美团商企通或其他美团业务API。需要在获得具体业务权限与文档后实现相应鉴权、数据映射和联调，不能用一个通用“美团Key”替代所有业务授权。

评分按rating/rating_max参与兴趣区内的推荐排序。不同平台评分口径仍可能不同，不能仅凭归一化断言质量等价；每轮使用当前选定的数据来源。缺评分保留未知；若通过时间检查的候选全部缺评分，明确回退为距离排序。
